Connect your Spotify app

One-time setup. The values are saved to a local .env file and never leave your machine except to talk to Spotify.

  1. Open the Spotify Developer Dashboard and click Create app. (Development Mode apps need the owner to have Spotify Premium.)
  2. Under Redirect URIs, add exactly:
    {{ settings.redirect_uri }}
    Spotify no longer accepts localhost; use 127.0.0.1.
  3. Tick Web API under “Which API/SDKs are you planning to use”, then save.
  4. In User Management, add the email of every Spotify account that will log in (up to 5 in Development Mode).
  5. Open Settings, copy the Client ID and Client secret, and paste them below.
